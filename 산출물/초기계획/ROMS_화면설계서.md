# ROMS (Runner's Overwatch Match System) 화면 설계서

> **문서 버전**: v1.0  
> **작성일**: 2026-07-28  
> **기준 산출물**: ROMS 프로젝트 요구사항정의서 (`CM-001` ~ `AD-003`)

---

## 1. 정보 아키텍처 (Information Architecture - IA)

```
ROMS System
│
├── [User Portal]
│   ├── 메인 대시보드 (SCR-001)
│   │   ├── 통합 검색바 (선수명)
│   │   ├── 시즌/랭킹 숏컷
│   │   └── 통합 지표 대시보드 (Top 5 / 최다 지표)
│   │
│   ├── 스트리머(선수) 상세 (SCR-002)
│   │   ├── 개요 탭 (모스트 영웅, 승률, 하이라이트 영상)
│   │   ├── 업적 탭 (참여 대회 결과 목록)
│   │   ├── 경기 맵별 결과 탭 (상세 KDA, 스탯, 사용 영웅)
│   │   ├── 맵별 데이터 탭 (맵별 승/패/승률)
│   │   └── 선수 비교 탭 (1v1 상대 전적)
│   │
│   ├── 시즌 아카이브 (SCR-003)
│   │   ├── 대진표 (토너먼트 트리)
│   │   ├── 스케줄 (일정 및 결과)
│   │   ├── 팀 목록 & 맵풀
│   │   ├── 경기 결과 상세 (세트 스코어, VOD, 스탯)
│   │   └── 시즌 통계 (픽률/승률)
│   │
│   └── 랭킹 (SCR-004)
│       ├── 선수 랭킹 (우승, KDA 등)
│       ├── 영웅 랭킹 (픽률, 픽 모스트)
│       └── 맵 랭킹 (최다 플레이 맵)
│
└── [Admin Portal] (로그인 제어)
    ├── 대회/시즌 및 팀 관리 (SCR-005)
    ├── 선수 배정 및 포지션 관리 (SCR-006)
    └── 경기 결과 & 스탯 입력 (SCR-007)
```

## 2. 화면 목록 (Screen List)

| 화면 ID | 화면명 | 주요 관련 요구사항 | 접근 권한 |
